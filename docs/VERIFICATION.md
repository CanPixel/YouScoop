## Repeatable checks

- Shared archive core: 3 unit and 20 preservation integration tests passed.
- YouScoop native library: 31 tests passed, including grouped citations and exclusion of fabricated raw Omni text from chat retrieval. Python runtime: 9 tests passed.
- Both frontends passed lint and production Vite builds. Both standalone macOS `.app` bundles built in debug mode and remained running after launch. These bundles include native app code and frontend assets, but the optional model weights are installed into Application Support on first setup.
- ARM64 Android release APK built at 31 MB, then was signed with the local default debug key for preview testing. This is not a Play Store signing key. The emulator release app remained running after launch.
- The genuine Android integration test passed all assertions through the app WebView and native commands. It does not substitute for a physical Fold or full interactive manual review.
- Full raw twelve-clip output and native cancellation, handoff, ARM64 storage, and voice results are saved under `experiments/model-trial/results/final-verification/`. The new isolated archive receipt records 112 searchable passages while preserving all 69 artifacts. The new native review test confirms a written observation enters search and export and can be removed again. The raw Omni output contains errors; inspect it before writing a reviewed observation.
- Artifact IDs and source revision IDs now include artifact content hashes. In an isolated archive, changing only the raw Omni output created a second preserved revision while leaving 112 current evidence passages; importing the identical version again kept the revision count at two. The user's desktop archive was empty during this check, so no existing archive revision needed migration.
- After this hash change, exporting the actual 32:45 source into a fresh isolated archive again produced 112 searchable passages and 69 preserved artifacts. The updated YouScoop macOS bundle was launched and remained running.
- The twelve-clip first-response run took 50.6 seconds including model loading and avoided the prior repeated fake conversation. It still included a clipped title card, a broad factual claim, and inaccurate scene or speech details. A visual-scene prompt across the same twelve clips took 39.9 seconds including loading and avoided quoted document values but often described only a person at a microphone. These results are in `omni-batch-first-response.json` and `omni-batch-visual-only.json`; they do not justify automatic promotion to archive evidence.
- YouScoop now offers visible-scene and joint-question presets for manual inspection, shows the exact question and aligned caption text next to each raw Omni output, and marks the archive copy as needing an update after source edits or inspection. The archive retains older revisions even when an observation is removed from the current source.
- The current package also passed an ARM64 Android emulator storage check: import and repeat import preserved 112 current evidence passages, and a complete library backup restored the same count. The native report is `sacri-android-current.json`; this is a package/storage check, not a physical Fold or full UI import test.

No model output or source allegation is labeled independently verified by these checks. Citation labels identify where the archive found text; they do not authenticate a document or establish that its speaker is correct.
